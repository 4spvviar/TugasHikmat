# TugasHikmat
Aplikasi desktop berbasis Windows Forms (C#) yang terhubung dengan database SQL Server.
[Aplikasi inventory untuk menyimpan barang atau menambahkan baran]

Teknologi
Komponen	Keterangan
Bahasa	C#
Kerangka	.NET 8 ( net8.0-windows)
UI	Formulir Windows
Basis data	Microsoft SQL Server
Perpustakaan	Microsoft.Data.SqlClient 6.1.2

Prasyarat
Windows 10/11 (Windows Forms hanya berjalan di Windows)
SDK .NET 8
SQL Server (misalnya SQL Server Express atau LocalDB)
Visual Studio 2022 (opsional, disarankan)
